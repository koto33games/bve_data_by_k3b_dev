【200系運転操作】
※BVE Trainsimの基本操作については割愛させていただきます。
非常ブレーキ＋Homeキー	：ATSの復帰操作をする
D(テンキーではない2)	：左側のドアを開く
E(テンキーではない3)	：両側のドアを閉める
F(テンキーではない4)	：右側のドアを開く
I(テンキーではない7)	：左側のドアブザーを鳴らす(長押し)
J(テンキーではない8)	：右側のドアブザーを鳴らす(長押し)
