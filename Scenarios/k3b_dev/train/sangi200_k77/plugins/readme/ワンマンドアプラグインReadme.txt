ワンマン・ツーマン切替について
Beacon85を通過した次の駅でワンマン、ツーマンが自動で切り替わります。
なお、ドアが開くまでは前の状態ですのでワンマン→ツーマンの場合はドアスイッチを操作してドアを開ける必要があります。ドアは自動で閉まります。
ツーマン→ワンマンの場合はドアが自動で開きますので、ドアスイッチを操作してドアを閉めてください。


始発駅から車掌が乗務する場合は、Beacon85を停止位置より手前に置いてください。
駅ジャンプ後ツーマンモードに切り替わる際は、それまでワンマンモードであってもドアが自動で開きます。ワンマンモードに切り替わる際は、ドアを手動で開けてください。
始発駅でブザーテストを行う場合は、始発駅より前にBeacon86を置いて、SendDataを1にしたうえで始発駅と次の駅の間にBeacon86を置いてSendDataを0にしてください。


ワンマンツーマンモードを切り替える際の注意点
ワンマンモードからツーマンモードへ切り替わる駅では、先に運転士がドアを開けてから車掌が乗り込みます。その後ドアが自動で閉まります。
ツーマンモードからワンマンモードへ切り替わる駅では、先に車掌ががドアを開けてからワンマン運転に切り替わります。その後乗降が終了したらドアを閉めてください。
路線製作者の方は、切替駅での停車時間を多めに取るよう設定してください。

Beacon85の設定方法
Beacon85を置く位置は、ツーマンの場合はBve構文でStationのmargin2、つまり1つ目の引数から200m後方に置いてください。ただし、ワンマンの場合は停止位置手前であれば問題ありません。通過駅には置かないでください。
Beacon85のSendDataにはmargin1とmargin2の絶対値を足した値*1000を入れて、ドアの方向が左の際には符号に-を付けてください。ただし、ワンマンの場合は0です。
以下に構文例を示します。
1つ目
$Station;
	Station['Sta'].Put(-1,-5.5,4);
$Station - 196;
	Beacon.Put(85,0,-9500);
2つ目
$Station;
	Station['Sta'].Put(1,-5,5);
$Station - 195;
	Beacon.Put(85,0,10000);

ツーマンモードからワンマンモードへ切り替わる際は以下のようにBeacon85を二つ使用して設定してください。
停止位置とドア方向の設定を行ったあと、1つ目のBeacon85と停止位置の間に2つ目のBeacon85を設置してください。

$Station;
	Station['Sta'].Put(1,-5,5);
$Station - 195;
	Beacon.Put(85,0,10000);//1つ目
$Station - 190;
	Beacon.Put(85,0,0);//2つ目

1つ目のBeacon85でドアの方向を指定し、2つ目のBeacon85でワンマンモードを指定しています。
始発駅をツーマンモードで設定する場合は、停止位置の手前であれば置く位置は構いません。

iniファイルの内部
[DATA]
closetime ドア閉ボタンを押してからドアが閉まるまでの時間(ms)
StartBuzzer 発車時のブザーを鳴らすかどうか(1:有効 0:無効)
BuzzerTest ブザー試験をするかどうか(1:有効 0:無効)
Adjust 停止位置ズレのブザーを鳴らすかどうか(1:有効 0:無効)
DIR 戸閉連動
[Key]
DoorL	:左ドア開(デフォルトD)
DoorC	:ドア閉(デフォルトE)
DoorR	:右ドア開(デフォルトF)
DoorCar	:全車自車切り替え(デフォルトG)
※該当するiniファイルが無い場合は自動生成されます。

※自動放送は再現しておりません。

二次配布について
当プラグインは素材として公開しておりますので、各自車両データ等に組み込んだり改造パッチにするなどで二次配布を許可しております。
ただし、バグ報告の収集のため、使用した旨を各データのReadme等にお書きのうえ、このReadmeをリネーム等するなどして同梱してください。

当プラグインは、Mackoy氏のサンプルプラグインを改造して製作しております。
iniファイルの読み込みにはamedas.氏のinimoniで出力されたソースを使用しています。
